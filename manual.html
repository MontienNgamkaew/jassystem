เข้าสู่ระบบ (Login)

เปิดเว็บไซต์จะพบหน้า Login สีแดง ให้กรอกข้อมูลดังนี้

  • 1
    กรอก ชื่อผู้ใช้งาน (Username) ที่ Admin กำหนดให้
  • 2
    กรอก รหัสผ่าน (Password)
  • 3
    กด เข้าสู่ระบบ — หากข้อมูลถูกต้องจะเข้าสู่หน้า Dashboard
ค่าเริ่มต้น: Username admin / Password admin1234 — ควรเปลี่ยนรหัสผ่านทันทีหลัง Login ครั้งแรก

หน่วยหน่วยนับชุด / เครื่อง / ครั้ง

    กด + เพิ่มสินค้า มุมขวาบน → กรอกข้อมูล → กด บันทึก
  • 2

จัดการแพ็กเกจ

เมนู แพ็กเกจ ใช้สร้างชุดสินค้าสำเร็จรูปที่มักขายรวมกัน เพื่อความรวดเร็วในการออกเอกสาร

  • 1
    กด + เพิ่มแพ็กเกจ → กรอก รหัส / ชื่อ / คำอธิบาย
  • 2
    เพิ่มรายการสินค้าพร้อมจำนวนและราคา → กด บันทึก
  • 3
    เมื่อออกเอกสาร กด เลือกแพ็กเกจ → ระบบจะดึงรายการสินค้าทั้งหมดมาใส่อัตโนมัติ
สามารถ บันทึกเป็นแพ็กเกจใหม่ ได้ตอนออกเอกสารด้วย — สะดวกเมื่อมีชุดสินค้าใหม่ที่ยังไม่เคยบันทึก

ออกเอกสารใหม่

เมนู ออกเอกสาร — หัวใจหลักของระบบ

ประเภทเอกสาร 3 ชนิด:

ใบเสนอราคา (QT) ใบแจ้งหนี้ (INV) ใบเสร็จรับเงิน (RE)
  • 1
    เลือก ประเภทเอกสาร และ วันที่
    เลขที่เอกสารออกอัตโนมัติ เช่น QT-202506-0001
  • 2
    เลือก บริษัทผู้ออกเอกสาร และ ลูกค้า จาก Dropdown
  • 3
    เพิ่มรายการสินค้า:
     • พิมพ์ รหัสสินค้า หรือ ชื่อ → ระบบ Auto-suggest
     • หรือกด เลือกแพ็กเกจ เพื่อเพิ่มทีละชุด
     • หรือกด Import CSV เพื่อนำเข้าจากไฟล์
  • 4
    ปรับ จำนวน และ ราคา แต่ละรายการได้โดยตรง ระบบคำนวณยอดรวมอัตโนมัติ
  • 5
    ตั้งค่าเพิ่มเติม:
     • ✅ รวม VAT 7% — เพิ่มภาษีมูลค่าเพิ่ม
     • ✅ แสดงวันที่บนเอกสาร
     • ✅ บันทึกเป็นแพ็กเกจใหม่ — สำหรับชุดสินค้าที่ต้องการใช้ซ้ำ
  • 6
    กด บันทึกเอกสาร — ระบบจะสร้างเลขที่เอกสารและบันทึกลงฐานข้อมูล
เลขที่เอกสาร จะออกตามลำดับแยกตามประเภทและเดือน เช่น QT-202506-0001, INV-202506-0001
ประวัติเอกสาร

เมนู ประวัติเอกสาร แสดงเอกสารทั้งหมดพร้อมเครื่องมือค้นหาและกรอง

ฟีเจอร์วิธีใช้
ค้นหา พิมพ์เลขที่เอกสาร หรือชื่อลูกค้า ในช่องค้นหา → กด Enter
กรองประเภท เลือก Dropdown: ทั้งหมด / ใบเสนอราคา / ใบแจ้งหนี้ / ใบเสร็จ
เรียงลำดับ กดหัวตารางเพื่อเรียงลำดับตามคอลัมน์นั้น ๆ
แปลงเอกสาร กดปุ่ม แปลง ในแถว → ระบบสร้างเอกสารประเภทถัดไป (Quote→Invoice→Receipt) พร้อม prefill รายการอัตโนมัติ
ดาวน์โหลด PDF กดปุ่ม PDF ในแถว หรือเข้าดูเอกสาร → กด พิมพ์ / Export PDF
แก้ไข กดปุ่มแก้ไขในแถว → แก้ไขรายการ จำนวน ราคา
ลบ กดปุ่มลบ → ยืนยัน (ไม่สามารถกู้คืนได้)

ดูเอกสาร และ Export PDF

กดที่ เลขที่เอกสาร หรือปุ่ม เพื่อเข้าดูหน้า Preview เอกสาร

  • 1
    หน้า Preview แสดงเอกสารตามรูปแบบ PDF จริง พร้อมโลโก้ / ที่อยู่บริษัท / ตราประทับ
  • 2
    กดปุ่ม Download PDF เพื่อดาวน์โหลดไฟล์ PDF
  • 3

PDF รองรับ ภาษาไทย เต็มรูปแบบ มีช่องลายเซ็น และแสดง ยอดเงินเป็นตัวอักษร อัตโนมัติ
จัดการข้อมูลบริษัท

เมนู จัดการข้อมูลบริษัท — กำหนดข้อมูลผู้ออกเอกสาร รองรับหลายบริษัท

ฟิลด์รายละเอียด
ชื่อบริษัท (ไทย / อังกฤษ)แสดงในหัวเอกสาร
ที่อยู่แสดงในเอกสาร
เบอร์โทรศัพท์แสดงในเอกสาร
เลขประจำตัวผู้เสียภาษี13 หลัก แสดงในเอกสาร
โลโก้บริษัทไฟล์รูป PNG/JPG แสดงมุมซ้ายบนของ PDF
ตราประทับ / ลายเซ็นแสดงช่องลายเซ็นผู้มีอำนาจ
บริษัทเริ่มต้น บริษัทที่ถูกเลือกอัตโนมัติเมื่อออกเอกสาร
  • 1
    กด + เพิ่มบริษัท → กรอกข้อมูลและอัปโหลดโลโก้ → บันทึก
  • 2
    กดปุ่ม ตั้งเป็นค่าเริ่มต้น เพื่อให้บริษัทนั้นถูกเลือกอัตโนมัติ
  • 3
    แก้ไขโลโก้หรือตราประทับได้ที่ปุ่ม แก้ไข
ต้องมีบริษัทอย่างน้อย 1 บริษัทในระบบเสมอ — ไม่สามารถลบบริษัทสุดท้ายหรือบริษัทค่าเริ่มต้นได้
จัดการผู้ใช้งาน Admin เท่านั้น

เมนู จัดการผู้ใช้งาน แสดงเฉพาะผู้ใช้ที่มี Role เป็น Admin

ระดับผู้ใช้งาน:

Admin
  • เข้าถึงทุกเมนู
  • จัดการผู้ใช้งาน
  • ลบเอกสาร
  • จัดการบริษัท
User
  • ออกเอกสาร
  • ดูประวัติเอกสาร
  • จัดการสินค้า / ลูกค้า
  • ดู Dashboard
  • 1
    กด + เพิ่มผู้ใช้งาน → กรอก Username / ชื่อ / รหัสผ่าน / Role
  • 2
    แก้ไข: เปลี่ยนชื่อ, Role, หรือ Enable/Disable บัญชีได้
  • 3
    ลบผู้ใช้: กดปุ่ม ลบ (ไม่สามารถลบบัญชีตัวเองได้)
รหัสผ่านต้องมีความยาวอย่างน้อย 6 ตัวอักษร — ระบบเก็บด้วย bcrypt hash (ปลอดภัย)
คำถามที่พบบ่อย (FAQ)

เลขที่เอกสารออกอัตโนมัติอย่างไร?

ระบบนับตาม ประเภท + เดือน เช่น QT-202506-0001 หมายถึง ใบเสนอราคา มิ.ย. 2025 ฉบับที่ 1 เลขจะเริ่มใหม่ทุกเดือน

แปลงใบเสนอราคาเป็นใบแจ้งหนี้อย่างไร?

ไปที่ ประวัติเอกสาร → กดปุ่ม แปลง ในแถวที่ต้องการ → ระบบ prefill รายการทั้งหมดมาให้ → กด บันทึก ได้เลย

สามารถออกเอกสารในชื่อหลายบริษัทได้ไหม?

ได้ — เพิ่มบริษัทได้หลายบริษัทในเมนู จัดการข้อมูลบริษัท แต่ละเอกสารเลือกบริษัทผู้ออกได้อิสระ

PDF ไม่มีตราประทับ ทำอย่างไร?

ไปที่ จัดการข้อมูลบริษัท → แก้ไขบริษัท → อัปโหลด ตราประทับ / ลายเซ็น และเปิดใช้งาน

ลืมรหัสผ่าน ทำอย่างไร?

ให้ Admin เข้าไปที่เมนู จัดการผู้ใช้งาน → แก้ไขรหัสผ่านให้

Import CSV สินค้าได้ไหม?

ได้ — ตอนออกเอกสาร กดปุ่ม Import CSV ในส่วนรายการสินค้า ไฟล์ CSV ต้องมีคอลัมน์: code, name, unit, qty, price

เอกสารที่ลบไปแล้วกู้คืนได้ไหม?

ไม่ได้ — การลบเอกสารเป็นการลบถาวรจากฐานข้อมูล ควรตรวจสอบให้แน่ใจก่อนกด ยืนยัน
